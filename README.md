# VERDI · Control de Estacionamientos

Aplicación para registrar entradas, salidas y retornos de vehículos en el acceso del Edificio VERDI.

## Flujo operativo
- Tablero de **Vehículos dentro** con botón `SALIÓ` de un toque.
- Tablero de **Salieron recientemente** con botón `ENTRÓ` de un toque para registrar retornos sin volver a escribir la placa.
- Los movimientos pueden intercalarse: vehículo A sale, vehículo B sale, vehículo A entra, vehículo C sale, vehículo B entra, etc.
- Búsqueda directa por placa o por departamento.
- Cada permanencia conserva su entrada y salida; un retorno inicia una nueva permanencia.
- Bicicletas: asociadas a un Dpto., con cochera opcional.
- Cocheras alquiladas: el responsable puede ser un tercero que no vive en el edificio y se identifica por cochera/nivel, sin obligar a registrar un Dpto.

## Infraestructura
- 147 espacios de estacionamiento.
- S1: 1–43
- S2: 44–89
- S3: 90–136
- S4: 137–147

La asignación exacta de cada cochera a cada Dpto. queda pendiente de la relación oficial que proporcione la administración; no se inventan asignaciones.
