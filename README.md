# VERDI Control de Estacionamientos

Prototipo web responsive para tablet y PC.

## Prueba rápida

1. Abrir `index.html` en un navegador.
2. Seleccionar una placa de prueba o escribirla.
3. Pulsar **Buscar**.
4. Registrar **ENTRADA** y luego **SALIDA**.
5. Probar una placa inexistente para comprobar el rechazo.

Placas demo: `ABC-123`, `VER-001`, `XYZ-789`.

> Esta primera versión usa almacenamiento local del dispositivo para permitir pruebas inmediatas. La integración definitiva con Supabase se realizará sobre el mismo flujo, manteniendo el historial centralizado y controles de autenticación/RLS.
